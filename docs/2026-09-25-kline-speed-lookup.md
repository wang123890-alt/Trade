# 2026-09-25 交易頁互填 + K 線加速

協作看這篇。覆盤頁仍 WIP，這次只改載入路徑。

## 用戶要求

- 交易頁：代號、名稱擁一即可，另一欄自動完成
- 僅買進、尚未賣的持股 K 圖等很久仍空
- 其他 K 圖也要等一會，要縮短

## 原因

明細頁、覆盤頁仍是證交所失敗後才打雅虎。
瀏覽器直接證交所常被 CORS 檔，先等直接 1.8–2.5 秒再走中繼，再一個月一包，僅買進那條路會僅走這條慢路。

`loadKLineFast` 已寫好但沒接進畫圖。

## 改法

- 明細 / 覆盤改走 `loadKLineFast`：證交所與雅虎同時跑，誰先有棒就畫
- 同一檔股正在拉時不重覆請求；成功後記憶體 + localStorage 20 分
- 證交所單月：直接與中繼一起競速，不再先等直接超時
- 交易表單：代號約 4 碼或名稱 2 字就查，不用等離開欄位
  - 代號 → 名稱：本機記憶 / 交易 / 觀察名單 / MIS
  - 名稱 → 代號：只能對到已經交易或觀察過的名（沒有全市場名冊 API）

## 未改

FIFO / 損益 / Excel / 覆盤版面結構。
