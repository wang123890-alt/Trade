### 趨勢三態（程式現況）
- 多頭：MA5 > MA20 > MA60
- 空頭：MA5 < MA20 < MA60
- 其餘：range，畫面仍寫「橫盤（盤整）」（尚未寫入新用語）

### 用語（暫時先這樣，尚未寫入程式）
- 橫盤＝盤整：躺著走，不死板拆
- 箱子回來 → 區間
- 高低亂甩 → 震盪
- ADX<25 不是上列任一態的定義

### 進場（須同時成立才顯示參考進場區）
1. MA5 > MA20 > MA60
2. 收盤價 > 前 20 日最高價
3. ADX(14) ≥ 25
4. 成交量 ≥ 1.0× 二十日均量（不縮量）

### 出場旗標
- 收盤 < MA5 且 MA5 < MA10 → 參考出場「條件成立」
- 停損／2R 目標仍顯示為參考線，主出場看均線旗標

### 個股頁
