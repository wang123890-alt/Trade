## 已寫入 js/core/tradeLevels.js

### 進場（須同時成立才顯示參考進場區）
1. MA5 > MA20 > MA60
2. 收盤價 > 前 20 日最高價
3. ADX(14) ≥ 25
4. 成交量 ≥ 1.0× 二十日均量（不縮量）

### 出場旗標
- 收盤 < MA5 且 MA5 < MA10 → 參考出場「條件成立」
- 停損／2R 目標仍顯示為參考線，主出場看均線旗標

### 個股頁
- 未滿足進場條件時顯示缺哪一條
- 新增「參考出場」列
