## 暫定最佳規則

### 進場（須同時成立）
1. MA5 > MA20 > MA60（多頭排列）
2. 收盤價 > 前 20 日最高價（突破）
3. ADX(14) ≥ 25（震盪／弱趨勢不進）
4. 成交量 ≥ 1.0× 或 1.2× 二十日均量（量能門檻尚未最終二選一）

### 出場
- 收盤 < MA5 且 MA5 < MA10

### 頻率目標
- 一年最多約 50 筆（全組合計）
- 若只要 ADX≥25、不加嚴量能：樣本上約 90～110 筆／年
- 若要壓近 50 筆／年：可改 ADX≥35 且量 ≥ 1.2×均量（單筆平均略降）
