## 已寫入 js/core/tradeLevels.js

### 趨勢三態（程式現況）
- 多頭：MA5 > MA20 > MA60
- 空頭：MA5 < MA20 < MA60
- 其餘：range，畫面仍寫「橫盤（盤整）」（與新用語不一致，尚未寫入）

### 用語規則（已記錄，尚未寫入程式）
- 箱子（有上下緣）→ 區間
- 呈一條橫線→ 橫盤
- 無上下頂底→ 震盪；幅度大→ 劇烈震盪；幅度小→ 震盪
- 盤整：無多空方向的總稱，不替代區間或橫盤
- ADX<25 不是上列任一態的定義

### 進場（須同時成立才顯示參考進場區）
1. MA5 > MA20 > MA60
2. 收盤價 > 前 20 日最高價
3. ADX(14) ≥ 25
4. 成交量 ≥ 1.0× 二十日均量（不縮量）

### 出場旗標
- 收盤 < MA5 且 MA5 < MA10 → 參考出場「條件成立」
- 停損／2R 目標仍顯示為參考線，主出場看均線旗標

### 個股頁
- 未滿足進場條件時顯示缺哪一條
- 新增「參考出場」列
