# 覆盤前的規劃（2026-09-23）

協作看這篇。使用者：記錄；加入覆盤前的規劃。程式尚未改。

## 為什麼覆盤前要先有規劃

現在個股頁順序：K 圖 → 看法紀錄 → 虧損覆盤。
覆盤（`js/features/review.js`）只能看已成交的虧損：幅度、持有天數、是否攪平、部位比重、是否趕快回補、策略勝率。

它**看不到進場當下的計畫**。之前有過一條假規則「未設定停損」，實際只是證券商 CSV 沒寫理由，已刪掉。沒有規劃欄位，覆盤不能假裝量到「有沒按計畫出場」。

順序應該是：**先計畫，交易後再拿計畫對照覆盤**。

## 規劃要有什麼（尚未寫入）

進場前或輕倉時手寫，跟單一筆 BUY 紊在一起：

- 為什麼進（一句話）
- 停損價
- 目標價（或 R 倍）
- 部位上限（占投組成本比）
- 允不允許往下加碼
- 使用的策略標籤（已有，可並用）

覆盤時才能問：出場是不是碰到計畫的停損／目標？部位有沒超規劃？加碼有沒達反「不攪平」？

## 畫面位置（尚未寫入）

個股頁：K 圖 → **規劃** → 看法紀錄 → 虧損覆盤  
規劃在覆盤上方，不要嵌進覆盤卡裡。

## 不要做的

- 不要用「備註有沒寫停損二字」當成規劃
- 不要在沒欄位前把舊規則加回去
- Excel、FIFO、稅費不動
