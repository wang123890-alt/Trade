# 覆盤要什麼（2026-09-23）

協作看這篇。覆盤是要知道：買賣基於什麼、有無遵守規則、為什麼賺為什麼賠。
不用精確計畫價異於成交價當考卷。

## 欄位（交易表單已寫入）

`createTransaction` / 新增交易：

| 欄 | 值 | 說明 |
|---|---|---|
| reason | 文字 | 進出場原因（原有） |
| ruleTrend / ruleBreakout / ruleAdx / ruleVolume | '' / yes / no | 買進**當日**四條規則，不是今天重算 |
| ruleExitFlag | '' / yes / no | 賣出當日：收盤<MA5 且 MA5<MA10 |
| followedRules | '' / yes / no | 有無遵守規則 |
| pnlKind | '' / rule / broke | 規則內試錯 / 沒守規則 |

空字串＝未填（舊 CSV 單）。未填不列入合規率。
策略標籤欄仍在表單，定案是合進原因、尚未拿掉。

## 覆盤頁（預覽定案，頁面尚未寫入）

頂三格：合規筆數、規則內損益合計、沒守規則損益合計。
下面每筆已平倉：原因、當日進場四條、出場旗標、有無遵守、歸類標籤、實際盈虧。

現有個股頁「虧損覆盤」仍是 review.js 結果型態標籤，與這頁不同。
