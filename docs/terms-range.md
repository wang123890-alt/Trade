# 趨勢用語規則

記錄：2026-09-18
狀態：只寫 docs，程式尚未依此拆分。

使用者定義：寬幅、無上下頂底 → 簡單叫震盪；真要分幅度時，大叫劇烈震盪、小叫震盪。

## 1. 有方向

- 多頭排列：MA5 > MA20 > MA60
- 空頭排列：MA5 < MA20 < MA60

與橫盤、震盪分開計。

## 2. 有上下緣（畫得出箱子）

總稱：橫盤、盤整。

- 區間震盪／箱型：箱頂箱底清楚，價格在區間回來
- 一線／狀幅橫盤：幾乎一條橫線，振幅很小（道氏常見講法約3週以上、5%內）

均線交叉、糾結、無序，也歸在橫盤（盤整）這一粒。

## 3. 無上下頂底（畫不出箱子）

總稱：震盪。

- 振幅小：震盪
- 振幅大：劇烈震盪

不要把這類叫橫盤。

## 4. 不混用

- ADX < 25：另一道過濾（趨勢力道不夠），不是橫盤或震盪的定義
- 「震盪不進」舊用語廢止，改說缺哪一條

## 5. 程式現況（2026-09-18）

tradeLevels.js 只有三態：up / down / range。
range 畫面字：「橫盤（盤整：均線交叉、糾結或無序）」。
尚未量箱子寬度，也尚未把「無頂底的震盪」從 range 拆出。要寫入再改程式。
