# 趨勢用語規則

記錄：2026-09-18
狀態：只寫 docs，程式尚未依此拆分。

使用者定義（2026-09-18 晚）：
- 箱子（有上下緣）→ 區間
- 呈一條橫線→ 橫盤
- 寬幅、無上下頂底 → 震盪；幅度大 → 劇烈震盪；幅度小 → 震盪

## 1. 有方向

- 多頭排列：MA5 > MA20 > MA60
- 空頭排列：MA5 < MA20 < MA60

## 2. 區間

有箱頂、箱底，價格在兩條水平緣之間回來。
不再把箱子叫橫盤。

## 3. 橫盤

走勢幾乎一條橫線，振幅很小。
與「區間」分開計。

## 4. 震盪

無清楚上下頂底，畫不出箱子。
- 小：震盪
- 大：劇烈震盪

不要叫橫盤，也不要叫區間。

## 5. 盤整

盤整可作總稱（沒多空方向），不作為區間或橫盤的替代名。
均線交叉、糾結、無序：先仍歸「沒排好多空」，要不要再拆進區間/橫盤/震盪，看圖形不看光均線。

## 6. 不混用

- ADX < 25：趨勢力道不夠，不是上列任一態的定義
- 舊句「震盪不進」「區間盤整當橫盤」廢止

## 7. 程式現況

tradeLevels.js 只有 up / down / range。
range 畫面仍寫「橫盤（盤整）」，與本規則不一致。要寫入再改程式。
